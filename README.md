# Glass Launcher

Launcher Windows dédié au serveur Project Zomboid communautaire. Automatise la préparation du jeu avant connexion (vérification Steam, version du jeu, mod Java, mods Workshop) — n'installe ni ne remplace Steam.

## Statut

En conception — le cahier des charges technique est finalisé, l'implémentation n'a pas encore commencé.

## Stack technique

- C# / .NET 8
- Avalonia UI (interface multiplateforme, développée sur macOS, ciblant Windows)
- Velopack (packaging & auto-update)
- Distribution via GitHub Releases
